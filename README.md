# number-guessing-game
A number guessing game created with Scratch for CS50x Project 0.

# How to Play

Choose one of the three levels:
1st->1-50: Guess a number from 1 to 50.
2nd->1-100: Guess a number from 1 to 100.
3rd->Custom: Choose your own maximum number.

The game generates a random secret number within the selected range.
Enter your guess when prompted.
The game will tell you whether the secret number is greater or smaller than your guess.
Keep guessing until you find the correct number.

The game also keeps track of the number of attempts. Guesses outside the selected range are considered invalid and do not count as attempts.

# Features

Custom number range
Randomly generated secret number
Greater/smaller hints
Attempt counter
Invalid input checking
Conditional statements and loops
